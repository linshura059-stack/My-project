# Sok Sophea - Web Developer Portfolio

An interactive, high-performance web portfolio for **Sok Sophea**, rewritten into **React 19 + TypeScript + Vite + Tailwind CSS**.

## Features

- **Storm Canvas & Lightning Simulation Engine**: Real-time procedural rainfall and photorealistic multi-stage lightning strikes (stepped leader, cloud radial gradient flare, return stroke with ground flash, and electric-blue afterglow). Clicking the background or using the "Strike" button triggers a lightning bolt at the cursor coordinates. Includes automatic reduced-motion detection.
- **Tech Constellation & Floating Orbs**: 19 floating technology orbs (React, HTML, CSS, JavaScript, TypeScript, Bootstrap, Laravel, PHP, MongoDB, Figma, Next.js, GitHub, Vercel, GitLab, Vue, API, Postman, Tailwind, Node.js) with boundary bouncing and pointer-repulsion physics.
- **Neon Headers with Ignition & Ripple Waves**: Dynamic headers featuring sequential letter ignition, sine ripple waves, and periodic random neon flicker.
- **Hero & Story**: Avatar with spinning rainbow conic-gradient halo, 3D mouse perspective tilt, and fallback initials. Bio highlighting background at the National Technical Training Institute (NTTI) and internship at Somnab Technology.
- **Education Timeline**: Glowing gradient track connecting Primary School, Secondary School, High School, and University (NTTI) with pulsing graduation cap icons.
- **Interactive 3D Skills Constellation**: 11 interactive skill cards (HTML, CSS, Bootstrap, JavaScript, React, PHP, Laravel, MySQL, GitHub, GitLab, Vercel) featuring individual brand colors, orbital rings with rotating satellites, floating micro-particles, shine sweeps, 3D perspective tilt, logo spin on hover/click, and travelling neon border comets.
- **Project Showcase (6 Featured Projects)**:
  1. **Inventory Dashboard** (Laravel + MySQL + Bootstrap 5)
  2. **Travel Guide** (React.js + TypeScript + Bootstrap 5)
  3. **Phone Store** (HTML + CSS + JavaScript + Bootstrap 5) — Live demo at [phoneshop-deploy.vercel.app](https://phoneshop-deploy.vercel.app/)
  4. **Bike Rental System** (PHP + MySQL + Bootstrap 5)
  5. **My Portfolio** (React.js + Laravel + Bootstrap 5)
  6. **Task Management System** (JavaScript + React.js + Bootstrap 5)
  Includes 3D laptop frames, vector screen mockups, custom RGB color glows, stack badges, and interactive inspection modals.
- **Contact & NTTI Google Map**: Validated contact form with shake error feedback, submission spinner, and mailto fallback, alongside an interactive Google Map for NTTI Phnom Penh with an "Open in Maps" shortcut.
- **Navigation & Footer**: Responsive navbar with animated neon teal underline, route indicator, mobile drawer menu, and brand-colored glowing footer contacts.
